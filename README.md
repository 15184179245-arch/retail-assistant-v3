# 零售助手 V3 · 脱敏源码

> **面试速览：** Android 应用和 Python 服务来自本地实际项目。想现场试一下，可用离线入口查商品、看库位、生成热敏价签。


这份目录以 V3 本地工作树为基线，保留 Android 应用与 Python 服务的主目录和实际源码，不包含原项目 Git 历史、真实数据库、原接入地址和身份凭据。

## 打开演示（Mac / Windows）

下载 ZIP 后解压，双击 `offline-demo/index.html` 可直接预览。需要现场运行时，进入 `offline-demo`，执行 Mac 的 `python3 run_demo.py` 或 Windows 的 `py -3 run_demo.py`。该入口仅使用合成数据，浏览器在本机查询内存库，生成标签命令，不需要登录或连接原系统。

## 主项目源码

- `android-v2/`：原 Android 界面、数据层、Room 迁移与本地业务代码。Room 现在只初始化虚构商品，声音和图标使用新生成的占位素材。Android 完整构建未验证。
- `src/`：Python 服务的实际源码。生产配置、原数据库、外部服务的权限以及需单独审核的材料不随公开版交付，不能用它直连原业务，其他生产服务链路也未验证。

没有任何原库存、进货、销售、订单、现场音频和原运行凭据被作为示例装入公开版。

Python 服务源码需 Python 3.10 或更新版本；在线搜索模块另外需要 jieba 等项目依赖。macOS 自带的旧版 Python 可以用于上面的离线浏览器演示，但不保证能运行主服务。
